# Juego Dinámico

## Descripción
Este es un juego dinámico, creativo e infinito por niveles desarrollado en HTML5, CSS3 y JavaScript. El objetivo del juego es mantenerse lo más tiempo posible evitando obstáculos.

## Funcionalidades
- Niveles infinitos que aumentan de dificultad.
- Puntuación que incrementa con el tiempo.
- Visualización de nivel actual y puntuación en la pantalla.

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript

## Instrucciones de Uso
1. Abre el archivo `index.html` en un navegador web.
2. El juego comenzará automáticamente y se actualizará continuamente.
