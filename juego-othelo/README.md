# Juego de Othelo

Este es un juego de Othelo implementado en HTML, CSS y JavaScript.

## Instrucciones
1. Abre el archivo `index.html` en un navegador.
2. Haz clic en el botón 'Comenzar Juego' para iniciar.
3. Juega haciendo clic en las casillas del tablero.

## Funcionalidades
- Tablero de 12x12.
- Dos jugadores (negras y blancas).
- Lógica de movimiento y captura de fichas.
